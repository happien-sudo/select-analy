대시보드 사용 방법 및 엑셀 파일 업로드 안내

1. 구글 스프레드시트에서 엑셀 파일 다운로드

  1. 학교 구글 스프레드시트 파일을 엽니다.
  2. 상단 메뉴에서 [파일] → [다운로드] → [Microsoft Excel(.xlsx)]를 클릭하여 컴퓨터에 저장합니다.
  3. 웹앱 상단의 [엑셀 파일 찾아보기] 버튼을 누르거나 점선 영역에 파일을 끌어다 놓으시면 모든 시트가 자동으로 즉시 분석됩니다!

2. 지원하는 시트명 및 양식

  • 시트 자동 분류: 시트명에 2-1, 2학년 1학기, 3-1, 3학년 1학기 등이 포함되어 있으면 자동으로 해당 학기 탭에 매칭됩니다.
  • 다양한 양식 지원: 선택1~선택5 열에 과목명이 적힌 양식, 과목별로 체크(1, O)된 양식, 설문 응답 텍스트 양식을 모두 자동으로 인식합니다.

3. 깃허브(GitHub Pages) 무료 배포 안내

이 프로젝트는 백엔드 서버가 필요 없는 정적 웹앱입니다. GitHub 저장소에 index.html, style.css, app.js를 올리신 후, 저장소의 [Settings] → [Pages]에서 브랜치를 main으로 켜두시면 어디서나 접속할 수 있는 웹사이트가 됩니다.

4. 교육과정 전문가 분석 도구 활용 팁

  • 분반 시뮬레이터: 학급당 기준 인원 슬라이더를 조절하여 개설 학급 수 및 교원 수급 시수를 사전 예측할 수 있습니다.
  • 시간표 동시선택 분석: 함께 많이 신청한 과목을 식별하여 시간표 충돌이 없는 최적의 블록(선택군)을 설계할 수 있습니다.
  • 물·화·생·지 4과목 분석: 2학년 1학기 자연계열 심화 학생들을 별도로 관리하고 진로 진학 상담에 활용할 수 있습니다.
