# 📚 과목 선택 결과 분석 대시보드 (2022 개정 교육과정)

**제작자: 정명고 오인석**

2022 개정 교육과정(고교학점제 172학점 체제)에 따라 학생들이 선택한 과목 신청 데이터를 분석하여 **과목별 신청 학생 수**, **예상 분반 수(25명 기준, 반올림)**, **교원 주당 필요 시수**, **시간표 동시선택 상관관계**, **소인수 대책** 및 **수강신청 오류 검증**을 원스톱으로 제공하는 모던 교육과정 분석 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **학교 지정 과목 & 학생 선택 과목 구분 및 교과군별 그룹화**
   - 모든 학생이 수강하는 **[📌 학교 지정 과목]**과 수요 조사 대상인 **[🎯 학생 선택 과목]**을 명확하게 분리.
   - 각 섹션 내에서 **교과군(`기초`, `사회`, `과학`, `체육·예술`, `생활교양`)별로 체계적으로 서브 그룹화**하여 표시.
   - 불필요한 `표준 과목명` 열을 없애고 직관적인 단일 과목명으로 깔끔하게 정돈.

2. **교육과정 전문가 도구 (분반·시간표)**
   - **분반 산출 시뮬레이터**: 학급당 기준 정원(15~35명, 기본 25명) 슬라이더를 실시간 조절하여 필요 분반 수(`Math.round(인원/기준)`), 분반당 평균 인원, 주당 필요 교원 시수(`분반 × 학점`), 개설 진단 실시간 계산.
   - **시간표 편성용 동시선택 상관관계 분석 (Top 15)**: 학생들이 동시에 많이 선택한 과목 쌍을 자동 분석하여, 시간표 충돌 방지를 위한 블록(선택군) 배치 권고 제공.
   - **소인수 과목 & 폐강 위기 대책**: 15명 미만 신청 과목을 식별하고 온·오프라인 공동교육과정 개설 또는 분반 운영 가이드 제공.

3. **학생별 선택 & 오류 검증**
   - **수강신청 유효성 검사**: 선택 규정(택4, 택1, 택5 등) 미달 또는 초과 선택 학생을 실시간 탐지하여 오류 사유(예: `선택 4과목: 3/4 (1개 미달)`) 안내.
   - **학생별 전 과목 조회**: 학기별, 학급(반)별(기본 1반) 필터링 및 이름/번호 검색, 학생별 선택 상세 모달.

4. **자연·이공계 특화 분석 (물·화·생·지 4과목 올선택 현황)**
   - 2학년 1학기 4대 기초 과학(물리학·화학·생명과학·지구과학)을 모두 선택한 이공계 집중 학생 수 및 비율 자동 집계, 전용 모달 및 엑셀 다운로드 제공.

5. **학교별 편제 반영 범용 엑셀 양식 (`과목명1, 과목명2...`)**
   - 하드코딩된 과목명을 탈피하여 모든 학교에서 자유롭게 적용할 수 있는 범용 엑셀 템플릿 다운로드 제공.
   - 1행: 이수 구분 및 선택군 표기 (`[학교지정]`, `[선택군1(택4)]`, `[선택군2(택1)]`)
   - 2행: 과목명 (`과목명1`, `과목명2`... 또는 학교 실제 과목명)
   - 5개 시트(`2-1`, `2-2`, `3-1`, `3-2`, `작성안내`) 포함.

6. **첫 화면 즉시 로딩 (355명 정밀 시뮬레이션 샘플 데이터)**
   - 접속 즉시 4개 학기 355명의 실제 학교 환경과 동일한 샘플 데이터가 탑재되어 있어 별도 파일 업로드 없이도 즉시 모든 기능을 체험 가능.

7. **개인정보 100% 안전 보호 (순수 클라이언트 로컬 연산)**
   - 서버 통신 없이 사용자의 웹 브라우저 메모리 안에서만 100% 동작하므로 학생 개인정보 외부 유출 우려가 전혀 없습니다.

## 🚀 GitHub Pages 배포 방법 (초간단 2분)

이 웹앱은 별도의 백엔드 서버나 빌드(Node.js 등) 과정이 필요 없는 순수 정적 웹 애플리케이션입니다.

1. **GitHub 저장소 생성 및 파일 업로드**:
   ```bash
   git init
   git add .
   git commit -m "feat: 과목 선택 결과 분석 대시보드 시스템"
   git branch -M main
   git remote add origin https://github.com/[사용자아이디]/[저장소이름].git
   git push -u origin main
   ```

2. **GitHub Pages 활성화**:
   - 저장소 페이지 상단의 **[Settings]** 클릭
   - 좌측 사이드바 메뉴에서 **[Pages]** 클릭
   - **Build and deployment** 항목의 **Branch**를 `main` (또는 `master`), 폴더를 `/ (root)`로 지정 후 **[Save]** 클릭
   - 1~2분 후 상단에 표시되는 `https://[사용자아이디].github.io/[저장소이름]/` 주소로 접속하시면 즉시 사용하실 수 있습니다!
