## 🚀 사용 방법

### 1. 웹앱 실행
- 폴더 내의 `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 웨일(Whale) 등 웹 브라우저로 열면 즉시 실행됩니다.

### 2. 엑셀 파일 업로드 및 지능형 자동 감지 (어떤 엑셀 양식이든 자동 인식)
1. 학교 구글 스프레드시트에서 **[파일] → [다운로드] → [Microsoft Excel(.xlsx)]**를 클릭하여 컴퓨터에 저장합니다.
2. 웹앱 상단의 **[엑셀 파일 찾아보기]** 버튼을 누르거나 점선 영역에 파일을 끌어다 놓으시면 모든 시트가 자동으로 분석됩니다.
3. **지능형 자동 감지 엔진(Universal Smart Parser)** 내장:
   - **열 위치 무관**: A열이 '이름'이든 '학번'이든, '반'/'번호'의 순서가 달라도 헤더 명칭을 스스로 찾아내어 매핑합니다.
   - **행 위치 무관**: 과목명이 1행, 2행, 심지어 4행에 적혀 있어도 상위 10개 행을 자동 스캔하여 과목명이 적힌 행을 스스로 감지합니다.
   - **학생 이름 유무 무관**: 개인정보 보호를 위해 학생 이름이 없어도 반/번호로 완벽 분석되며, 이름이 포함된 파일인 경우 이름까지 함께 표시 및 검색됩니다.
4. 언제든지 **[샘플 데이터 복원]** 버튼을 누르면 기본 시연용 데모 데이터로 다시 전환할 수 있습니다.

## 🌐 깃허브(GitHub Pages) 무료 배포 방법

1. [GitHub](https://github.com/)에 로그인 후 새 저장소(New Repository)를 생성합니다. (예: `select_analy`)
2. 이 폴더의 파일들(`index.html`, `style.css`, `app.js`, `README.md`)을 업로드(Commit & Push)합니다.
3. 저장소 상단의 **[Settings]** 탭으로 이동합니다.
4. 좌측 메뉴에서 **[Pages]**를 클릭합니다.
5. **Branch** 설정을 `None`에서 `main` (또는 `master`) 브랜치로 선택하고, 폴더는 `/(root)`로 지정한 뒤 **[Save]**를 누릅니다.
6. 약 1~2분 후 상단에 생성된 배포 URL(`https://[사용자명].github.io/select_analy/`)로 접속하시면 전 세계 어디서나 웹앱을 열어보실 수 있습니다!
