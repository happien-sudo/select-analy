# 🌐 Google Apps Script(GAS) 웹앱 배포 가이드

본 프로젝트는 구글 워크스페이스(Google Workspace) 또는 개인 구글 계정의 **Google Apps Script**를 통해 손쉽게 웹앱으로 배포할 수 있도록 제작되었습니다.

---

## 📌 3분 완성 배포 절차

### 1단계: Google Apps Script 새 프로젝트 만들기
1. [script.google.com](https://script.google.com/) 에 접속하여 로그인합니다. (또는 구글 드라이브에서 `+ 새로 만들기` > `더보기` > `Google Apps Script` 클릭)
2. 좌측 상단의 `제목 없는 프로젝트`를 클릭하고 프로젝트 이름을 지정합니다. (예: `선택과목_수요분석기`)

---

### 2단계: 백엔드 코드 (`Code.gs`) 복사 & 붙여넣기
1. 기본으로 생성되어 있는 `Code.gs` 파일을 엽니다.
2. 기존 내용을 모두 지우고, 본 저장소의 `gas/Code.gs` 파일 내용을 그대로 복사하여 붙여넣습니다.
3. 상단의 **저장(디스켓 아이콘)** 버튼을 누릅니다.

---

### 3단계: 웹 프론트엔드 파일 (`index.html`) 생성 및 붙여넣기
1. 왼쪽 메뉴의 파일 목록에서 **`+` (파일 추가)** 아이콘을 클릭한 뒤 **HTML**을 선택합니다.
2. 파일 이름을 반드시 **`index`** 로 입력하고 Enter를 누릅니다. (`index.html` 파일이 생성됩니다)
3. 생성된 `index.html`의 기본 내용을 모두 지우고, 본 저장소의 `gas/index.gas.html` 파일 전체 내용을 복사하여 붙여넣습니다.
4. 상단의 **저장(디스켓 아이콘)** 버튼을 누릅니다.

---

### 4단계: 웹앱으로 배포하기
1. 우측 상단의 파란색 **`배포`** 버튼 > **`새 배포`**를 클릭합니다.
2. 팝업창 좌측의 톱니바퀴 아이콘(유형 선택)에서 **`웹 앱`**을 선택합니다.
3. 배포 설정을 다음과 같이 입력합니다:
   - **설명**: `2022 개정 교육과정 선택과목 분석기 v1.0`
   - **다음 사용자 권한으로 앱 실행**: `나(사용자 이메일)`
   - **액세스 권한이 있는 사용자**: 
     - 학교 선생님들 및 전체 공개 원할 시: **`모든 사용자`**
     - 같은 학교 도메인 내에서만 사용할 시: **`[내 학교 도메인]의 모든 사용자`**
4. 우측 하단의 **`배포`** 버튼을 클릭합니다.
5. 화면에 나타나는 **`웹 앱 URL`**을 복사하여 교내 선생님들께 공유하시면 웹 브라우저에서 즉시 사용하실 수 있습니다! 🎉

---

## 💡 업데이트(수정) 반영 방법
코드를 수정한 뒤 반영할 때는:
1. `배포` > `배포 관리` 클릭
2. 활성 배포 선택 후 우측 상단의 연필 아이콘(수정) 클릭
3. 버전을 **`새 버전`**으로 선택 후 **`배포`** 클릭
